# Controlling What Agents Can Access

This tutorial walks through locking down exactly which tools an agent can reach. You'll register an MCP proxy, define scopes over the tools, resources, and prompts it exposes, bundle those scopes into roles, and grant different roles to different agents — so two agents calling the *same* proxy endpoint end up with different capabilities. By the end, you'll see the full authorization model in action end-to-end: resource → permission (scope) → role → assignment, and how it changes what a token an agent presents at the gateway can actually do.
